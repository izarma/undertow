## Overview

A visual novel about the shore.

Made for "[Game Off 2025](https://itch.io/jam/game-off-2025)" Game Jam on theme - `Waves`

Theme interpretation : Waves of emotions - we maybe swept away in them without realizing.

</details>

<details closed>
